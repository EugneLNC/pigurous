# LLM plans and learned compound choreography

`choreography-v3` restores independent stroke/orbit/ribbon/tunnel/spark/star materials and adds rose, Lissajous and hypotrochoid curves. Twelve operations control separate property channels; simultaneous translation and scaling remain parallel, and later calls override only the same property. The renderer receives no audio. Absolute beat times, optional 1/192-beat ticks plus residuals, closed-form geometry and a fixed seed support arbitrary seeks.

## Actual learned path

The student has 11,120,640 trainable parameters. Its inherited four-layer whole-track encoder and four-layer local encoder feed a learned 54-field plan distribution, a plan encoder and a four-layer 256-wide compound-action query decoder. Sixty-four learned queries and a predicted action count emit material, verb, object, timing and parameter fields. The joint/preference checkpoints additionally expose encoded plan tokens as decoder cross-attention memory; the pilot checkpoint keeps its original architecture flag. This new decoder is parallel, rather than autoregressive; overfull training intervals are recursively subdivided. Eight persistent object groups may each split into multiple instances. True chart geometry/accents remain auxiliary supervision, not direct human labels for the new primitive library.

Both inference variants use the same weights and primitive implementation. The no-LLM path executes the student's continuous predicted plan, matching the predicted-plan training branch; the LLM path injects a validated saved structured plan. The readable no-LLM plan summarizes the learned distribution. The synthetic demonstration compiler is **not called during inference**. Every group is already created, so invisible objects may prepare with the model's chosen transforms before a later entrance. The earlier forced-visible entrance repair was removed because it overwrote predicted verbs and exposed parameters without supervision for that verb. The prior repair-version results remain archived; final results use `predicted-comparison` and `predicted-fresh`. Draw reset and split/merge direction constraints remain primitive semantics, not an audio-to-style director.

## Supervision boundaries

Human charts supervise sampled aggregate density, center, spread, movement, angular alignment, opacity, scale and accents. This is a geometric projection; it does not reconstruct all entity identities, parents, chart aesthetics or sub-62.5ms motion. New-material demonstrations combine real DeepSeek macro plans, authored action expansion and chart motion/timing. They are marked `llm_unreviewed`, weight 0.25. Native-only training views have no new-material/verb loss. Explicit human choices upgrade **only fully covered action lifetimes and two-second plan bins** to weight 1; rejected overlapping events/bins receive zero aesthetic weight. Count loss upgrades only fully watched windows and is masked on rejected overlaps. Native geometry loss remains available. A selection never approves a whole song or becomes a blind-test vote.

Six training song pairs have 20-second audio/video excerpts in `/review.html`. The actual preference file chose 1A–5A and rejected both original candidates for song 6. After one regeneration round, the user chose **6R1A**, again only seconds 100–120. The accepted intervals total 120 seconds, covering 212 complete action lifetimes; 262 overlapping action lifetimes from rejected candidates have zero aesthetic weight. The original records, plan hashes and combined feedback are saved in `data/choreography-v3`; `artifacts/feedback-audit.json` verifies scope. Sampling boosts watched windows by 8 while assigning equal weights to their paired real/synthetic views. The second new candidate and the two original song-6 candidates stay rejected only in the reviewed interval. Unseen regenerated candidates never inherit an earlier rejection.

The user's preference for smooth, natural transitions is explicit visual direction, not a genre-to-template rule. New inference-only plans use it in a separately cached prompt (`music-director-v3`). Old plans and watched videos remain preserved. Changing materials in a newly generated `enter` call can set `blend_material: true`; the deterministic actuator then crossfades over the **model-predicted duration**. Old calls keep their original semantics. Cross-material `morph` also crossfades. This rendering behavior is not credited as new model learning.

## Commands

```text
choreo analyze song.ogg --features song.npz -o analysis.json
choreo plan analysis.json --provider deepseek -o plan.json
choreo student prepare data/actions-v3/manifest.json --plans data/choreography-v3 -o data/student-v3 --reviews data/choreography-v3/user-reviews.json
choreo student train data/student-v3/manifest.json --initialize artifacts/actions-server/best.pt --device cuda -o runs/student
choreo generate song.ogg --features song.npz --checkpoint student.pt --planner model -o model.json
choreo generate song.ogg --features song.npz --checkpoint student.pt --planner llm --plan plan.json -o llm.json
choreo render llm.json --audio song.ogg --width 1280 --height 720 --fps 30 -o llm.mp4
```

The plan command uses DeepSeek V4 Pro/high and the official Responses endpoint. A local Windows PowerShell bridge accesses the existing DPAPI credential only for the request; it never returns a key. The server and browser receive no credential. The API receives only timestamped musical observations, feature-similarity relations and the action specification, not audio, full embeddings or chart files. An atomic SQLite reservation ledger enforces the shared 100,000,000 input-plus-output-token ceiling. Output already includes reasoning; it is counted once. Pending/unknown usage remains reserved. Cached plan keys include the full observed analysis, candidate, requested model and prompt version. Failed or invalid requests stop after three attempts, never silently become the rule baseline.

## Corpus and experiments

Eighty new public Phira packages were requested: 66 unambiguous pairs, 14 extraction ambiguities. Native support, exact audio/title grouping and complete trajectory sampling leave 53 new accepted records. Together with the previous 56, `data/actions-v3` has 109 records, split 79/5/25; 20 new title groups are frozen as test before their model/LLM inference. Preflight corrections are recorded separately in `data/corpus-v3/holdout-preflight-history.json`. Source rights remain with creators; downloaded availability is not a redistribution license.

The initial server snapshot used 14 available demonstration records (10 train, 4 validation). It ran two epochs and resumed through epoch 7: 120 optimizer steps, 112 compatible inherited tensors, 0.232 GiB peak PyTorch allocation. The best epoch is 4. This is a small **unreviewed synthetic pilot**, not the final preference-trained checkpoint. Full checkpoints, hashes, receipts and logs are retained under `artifacts/student-pilot`. Existing action weights and server directories remain unchanged.

The larger joint snapshot used 115 demonstration records (85 train, 5 validation, 25 test metadata; test tensors were excluded from the server upload). It completed 11 epochs, 1,408 updates, and stopped after five validation epochs without improvement. Best epoch: 5; validation loss: 4.904388. It transferred 201 compatible tensors from the pilot and used plan cross-attention memory.

The preference snapshot used 117 records (87 train, 5 validation, 25 test metadata), including the two regenerated song-6 candidates. It ran two epochs, resumed, and stopped at epoch 5: **780 additional updates**. Best checkpoint: epoch 0; validation loss: 5.026911, which is worse than the joint baseline. Peak PyTorch allocation was 0.2346 GiB, excluding CUDA context/other processes. Both runs selected one permitted GPU at a time and retained at least 2,048 MiB free headroom. Server uploads were inventoried and hash verified before extraction into new owned subdirectories. No other server work was changed.

On the 212 fully watched training actions, preference training reduced student-plan material cross-entropy 1.852→1.400, verb cross-entropy 2.116→1.554, object cross-entropy 0.871→0.592 and active-parameter MAE 0.1255→0.1007. Demonstration-plan parameter MAE fell 0.1208→0.0977. These are **training imitation diagnostics**, not held-out aesthetic improvements. Exact results are in `artifacts/preference-reconstruction.json`.

The joint model's auxiliary motion MSE did not beat a constant training-mean predictor: validation 0.04917 vs 0.04533; test 0.04491 vs 0.04136. This failure and the preference stage's worse validation loss are retained. Plan/audio ablation differences establish sensitivity, not beneficial musical use. Synthetic field reconstruction is measured separately from true chart geometry. Nearest-neighbor screening includes 120-sample normalized-time object-control trajectories as well as descriptors; it cannot prove originality.

The preference checkpoint still does not beat the constant-mean motion baseline: validation 0.04771 vs 0.04559; test 0.04440 vs 0.04132. On validation windows, synthetic material/verb/object accuracies with a predicted plan are 0.228/0.284/0.699; active parameter MAE is 0.1221. These low material/verb scores and frequent predicted entrances are evidence of remaining degeneration. A spatial timing audit checked all prepared records against the executable tempo map (maximum rounding error below 0.00003 beat); the failed mean baseline is not explained by a hidden beat-grid mismatch. A negative-zero section-boundary inference bug was fixed and regression tested.

DeepSeek usage in this iteration is **3,531,376 reported tokens, 154 requests, zero unknown reservations**, below the 100,000,000 ceiling. It includes initial/duplicate requests, regenerated candidates and 25 inference-only style plans. Input and output are counted once. The preference run used physical GPU **5**, RTX 5090; the joint run used physical GPU 6. GPU 7 was never selected.

Same-song comparison is available at `/compare.html`, with common audio/playback time, hash-checked manual audio association, action JSON editing and SceneScore download. The default page now uses the preference-trained NWAD student. The rule, original action-model and mathematical references remain selectable and explicitly labeled. Model A/B never calls the synthetic demonstration compiler or rule director.

Condition experiments separate original/zero/shuffled audio with a fixed LLM plan, declared visual-plan transfer with fixed audio, and a declared beat-aligned other-song feature warp. The latter is a controlled feature replacement, not a claim that the other original recording had precisely identical BPM. Renderer and checkpoints are fixed. Existing five diagnostic songs have been used during development. The 20 new families remain outside training, but have been read by sequential pilot/joint/preference diagnostics; they are not claimed to be pristine independent confirmation. Source anonymization and blind ratings should be kept separate from iterative model diagnostics.

Full video pairs, diagnostic SceneScores and blinded materials are generated by `scripts/compare_students.py`, `scripts/render_student_batch.py`, and `scripts/publish_student_preview.py`. `scripts/evaluate_blind_votes.py` consumes actual A/B/tie CSV votes, groups repeated votes by song and bootstraps a 95% interval over song means. Blank templates remain pending. The current materials compare LLM planning with student planning; that comparison does **not** substitute for a separately trained full-vs-local-model experiment. The 60% preference / lower CI bound above 50% target remains unaccepted without actual ratings.

## Remaining research limitations

The action decoder regresses normalized continuous timing/parameters; export adds 1/192-beat ticks and exact residual annotations. It does not yet use a separate categorical spatial-bin/residual head. Cross-segment object state is maintained by execution and grammar, not a learned autoregressive state memory. A native-chart view trains geometric/accent auxiliary heads, rather than direct artist labels for every new action field. Shapes have authored analytic topology and internal deformation; the model learns their selection and external actions. Human aesthetic supervision currently covers only 120 seconds. These limits are part of the delivered research prototype, not solved capabilities.
